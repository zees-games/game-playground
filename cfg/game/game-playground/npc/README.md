An NPC profile here overrides the Q menu entry of the same id (`npc_chaser.yml` changes the Chaser) and states only the keys it changes; a new id needs `extra: {base: npc_chaser}` to clone an entry. Keys: `name`, `health`, `speed`, `sight`, `sight_angle`, `hearing`, `cost`, `menu: {category, sort, hidden}`. Operators override per server in `cfg/server/game/game-playground/npc/`, and admins edit live with `profile_edit set npc <id> <key> <value>`. The eight catalogue NPCs have a file each so the in-game workbench lists them, each stating the catalogue's own numbers.
